# Capture-flow prototype

[index.html](index.html) is the tracked copy of the exploratory "Camera chooses" interaction. It is a single HTML file with simulated scenes and research-derived exposure examples. It does not operate a camera.

Open it with agent-browser according to the repo instructions. The local gate checks JavaScript syntax and reducer immutability in Node without opening a browser. Original exploratory artifacts remain under the locally backed-up evidence tree.
